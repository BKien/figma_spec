# OCL Utility Definitions

```text
String.trim(): String
- Removes leading and trailing whitespace; internal whitespace is unchanged.

Date::today(): Date
- Returns the Gregorian calendar date of the request-start instant in the service timezone Asia/Saigon.
- Repeated calls in one operation return the same date; restaurant-local slot matching uses TimeUtils separately.

DateTime::now(): DateTime
- Returns the server request-start instant in UTC with millisecond precision, captured once per operation for challenge expiry and event timestamps.

Email::normalize(value: String): String
- Trims surrounding Unicode whitespace, applies Unicode NFC, and lowercases using locale-independent Unicode rules.
- Internal whitespace and dots remain unchanged; provider-specific alias rewriting is not applied.

PasswordHash::of(value: String): String
- Produces a self-describing Argon2id password hash using a fresh 16-byte random salt, 65536 KiB memory, 3 iterations, parallelism 1, and a 32-byte output.
- A postcondition equality refers to the hash generated by that invocation, rather than a fresh recomputation with another salt.

PasswordHash::matches(value: String, storedHash: String): Boolean
- Verifies the supplied plaintext password using the Argon2id parameters and salt encoded in the stored hash; malformed hashes fail verification.

CodeHash::matches(value: String, storedHash: String): Boolean
- Verifies the code against its HMAC-SHA-256 challenge digest using an external server key and a timing-safe comparison.

TokenHash::of(value: String): String
- Returns the HMAC-SHA-256 digest of the exact issued access-token bytes under an external token key; plaintext tokens are not stored.

PhoneCipher::matches(ciphertext: String, value: String): Boolean
- True when AES-256-GCM authentication/decryption succeeds and the recovered exact phone string equals the supplied value.
- The encryption key is external to persisted booking rows; invalid authentication returns false.

RequestFingerprint::of(command: CreateBookingCommand): String
- Returns the fingerprint used to compare a create-booking request with a previously accepted idempotency key.
- Uses SHA-256 over versioned UTF-8 canonical JSON of the submitted command fields, excluding the idempotency key and any supplied fingerprint.
- Object keys are sorted, optional omissions become explicit nulls, decimal values use exact strings, and UTC timestamps use a fixed millisecond representation.

TimeUtils::matchesSlotTime(startsAt: DateTime, localTime: String, timezone: String): Boolean
- True when converting startsAt to the supplied IANA restaurant timezone yields exactly the requested HH:mm local time.
- startsAt identifies a unique instant, so repeated local times during a clock change are compared by their represented instant; invalid timezone or local-time syntax returns false.

SequenceUtils::isAscendingByStartTime(items: Sequence(ReservationSlot)): Boolean
- True when items are ordered by (startsAt, id) ascending; empty and singleton sequences satisfy the test.

SequenceUtils::isDescendingByCreatedAt(items: Sequence(Booking)): Boolean
- True when bookings are ordered by (createdAt, id) descending; empty and singleton sequences satisfy the test.

SequenceUtils::isDescendingByCreatedAt(items: Sequence(Notification)): Boolean
- True when notifications are ordered by (createdAt, id) descending; empty and singleton sequences satisfy the test.

GeoTimeZone::forAddress(address: String): String
- Returns the IANA timezone of the unique geocoded restaurant address.
- Unresolved or ambiguous addresses produce an invalid result and reject the restaurant write; no timezone is guessed.
```

Service operations that form OCL contexts are outside this catalog. Hash creation for verification codes and contact-phone encryption follow the formats above; they are not separate helper operations declared by the active local UML.

## Utility Classes

```text
class String <<Primitive>> {
  +trim(): String
}

class Date <<Primitive>> {
  +today(): Date
}

class DateTime <<Primitive>> {
  +now(): DateTime
}

class Email <<Utility>> {
  +normalize(value: String): String
}

class PasswordHash <<Utility>> {
  +of(value: String): String
  +matches(value: String, storedHash: String): Boolean
}

class CodeHash <<Utility>> {
  +matches(value: String, storedHash: String): Boolean
}

class TokenHash <<Utility>> {
  +of(value: String): String
}

class PhoneCipher <<Utility>> {
  +matches(ciphertext: String, value: String): Boolean
}

class RequestFingerprint <<Utility>> {
  +of(command: CreateBookingCommand): String
}

class TimeUtils <<Utility>> {
  +matchesSlotTime(startsAt: DateTime, localTime: String, timezone: String): Boolean
}

class SequenceUtils <<Utility>> {
  +isAscendingByStartTime(items: Sequence(ReservationSlot)): Boolean
  +isDescendingByCreatedAt(items: Sequence(Booking)): Boolean
  +isDescendingByCreatedAt(items: Sequence(Notification)): Boolean
}

class GeoTimeZone <<Utility>> {
  +forAddress(address: String): String
}

```
